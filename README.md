## 📌 Project Overview

**LookMovie** is a data analysis project built to transform movie data into an interactive **Power BI dashboard**.

The project focuses on the complete analytical workflow: preparing raw data, cleaning and transforming it with **Power Query**, building an analytical model, creating **DAX measures**, and presenting the results through interactive visualizations.

The goal is to turn movie-level data into clear insights that can support content analysis and better business understanding.

## 🎯 Business Questions

This dashboard is designed to help answer questions such as:

- What are the main characteristics of the available movie catalog?
- How are movies distributed across categories and attributes?
- Which segments contribute most to the overall catalog?
- What patterns can be identified from the available movie data?
- How can interactive reporting make movie data easier to understand?

## 🛠️ Tools & Technologies

- **Power BI** — Dashboard development and interactive reporting
- **Power Query** — Data cleaning, transformation, and ETL
- **DAX** — Measures and analytical calculations
- **Data Modeling** — Structuring data for analysis
